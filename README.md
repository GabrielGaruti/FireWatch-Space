# FireWatch Space

## Tecnologia Espacial Aplicada ao Monitoramento Inteligente de Queimadas

O FireWatch Space é uma plataforma desenvolvida para monitoramento inteligente de queimadas, criada como projeto da Global Solution FIAP.

A solução utiliza conceitos de tecnologia espacial, análise climática e inteligência artificial para identificar áreas de risco, monitorar focos de incêndio e apoiar ações preventivas voltadas à preservação ambiental.

---

# Objetivo

Desenvolver uma solução digital capaz de auxiliar no monitoramento e prevenção de queimadas por meio da integração de dados ambientais, indicadores climáticos e análises preditivas.

---

# Problema

As queimadas representam um dos principais desafios ambientais da atualidade, causando:

- Destruição da biodiversidade;
- Emissão de gases poluentes;
- Impactos na saúde pública;
- Danos econômicos;
- Aumento dos riscos climáticos.

A identificação rápida e o monitoramento contínuo são fundamentais para minimizar esses impactos.

---

# Solução

O FireWatch Space oferece uma plataforma que permite:

- Monitoramento de focos de incêndio;
- Visualização geográfica das ocorrências;
- Alertas inteligentes;
- Dashboard ambiental;
- Indicadores climáticos;
- Simulação de análises preditivas por IA.

---

# Como Executar

Clone o repositório:

```bash
git clone https://github.com/SEU-USUARIO/firewatch-space.git
```

Acesse a pasta:

```bash
cd firewatch-space
```

Instale as dependências:

```bash
flutter pub get
```

Execute:

```bash
flutter run
```
